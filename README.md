# Checkpoint Final - Hanoi Engine em C

## Pronto para o aluno
- frontend/
- bridge/bridge.py
- src/main.c (protocolo)
- src/hanoi.h (contrato)
- src/hanoi.c (TODOs)
- build.bat e Makefile

## Trabalho do grupo
Complete somente `src/hanoi.c`.

## Windows
1. `build.bat`
2. `python bridge\bridge.py`
3. acesse `http://localhost:8080`

## Linux/macOS
1. `make`
2. `python3 bridge/bridge.py`
3. acesse `http://localhost:8080`

## Atenção
O executável deve escrever UMA linha de resposta por comando no stdout.
Não use printf() de depuração no stdout. Para depurar use stderr.
